SPECIAL CONSTRAINT ANALYSIS

Fixed Window vs Sliding Window Counter

Empirical evaluation of rate-limiting algorithms to satisfy the assignment's Comparison Rule constraint.

Approach A • Vulnerable

Fixed Window Counter

Slices time into rigid, static 60s windows and abruptly resets to zero at epoch boundaries.

Boundary Burst Test: 40 requests / 2 sec (200% Capacity)
Avg Decision Latency: 314 nanoseconds
Memory Complexity: O(1) (2 fields per key)
Fair-Use Verdict: FAILS: Allows 2x spike attack at edge
Approach B • Production Choice

Sliding Window Counter

Applies a weighted rolling decay to smooth traffic bursts across boundary transitions.

Boundary Burst Test: 21 requests / 2 sec (Strictly Capped)
Avg Decision Latency: 547 nanoseconds (Sub-microsecond)
Memory Complexity: O(1) (3 fields per key)
Fair-Use Verdict: PASSES: Protects backend databases
